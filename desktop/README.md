# EventNote デスクトップ版（.exe）

ブラウザ版（start.ps1）と同じ画面・機能を、Windows のデスクトップアプリとして動かします。

- **ポートを使いません**（localhost:8080 / 3000 は不要）。画面とバックエンドはアプリの中で直接つながります
- **通知は Windows の通知**で届きます。ウィンドウを閉じてもタスクトレイで動き続けます
- **ログイン時に起動**は、画面右上「🔔 通知オン」メニューかトレイアイコンの右クリックで切り替えます
- DB は MySQL です（MySQL は起動しておいてください）

## 作り方

`build-exe.bat` をダブルクリック → `release\EventNote Setup 1.0.0.exe` ができるので、実行してインストールします。

## DB の接続設定

`%APPDATA%\EventNote\.env`（初回起動時に作成）。トレイの「設定ファイル（DB 接続）を開く」からも開けます。
MySQL に接続できないときは、起動時にダイアログから設定ファイルを開いて直せます。

## 開発

- `run-dev.bat`（= `npm start`）… インストーラーを作らずに起動
- 画面やバックエンドのコードは `frontend/` と `backend/` のものをそのまま使います（`npm start` / `npm run dist` のたびに `app/` へコピー）
